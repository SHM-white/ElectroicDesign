# Vehicle/HMI UDP v1 协议（委托版）

所有整数域均使用**小端序**编码。数据报采用单播，长度上限为
96 字节。不会解码认证边界之后的任何字段。

## 数据包头（22字节）

| 偏移 | 大小 | 字段 |
| --- | ---: | --- |
| 0 | 2 | 魔数 `0x4454`（线上字节 `54 44`） |
| 2 | 1 | 版本 `1` |
| 3 | 1 | 消息类型：HEARTBEAT `1`、CAR_TELEMETRY `2`、TASK_SELECTION `3`、MISSION_STATUS `4`、DIAGNOSTIC `5` |
| 4 | 2 | 载荷长度，最大值 64 |
| 6 | 4 | 发送方 ID（uint32，非零） |
| 10 | 4 | 随机且非零的启动纪元（uint32） |
| 14 | 4 | 模 `uint32` 序列号 |
| 18 | 4 | 发送方单调毫秒数，仅供参考 |
| 22 | N | 载荷 |
| 22+N | 2 | CRC16-CCITT-FALSE，覆盖报头和载荷 |
| 24+N | 8 | HMAC-SHA256 的前 8 个字节，覆盖报头、载荷和 CRC |

## 接收规则

- 接收方使用本地单调接收时间执行 750 ms 遥测新鲜度门限，不使用发送方毫秒数。
- 序号前向距离必须位于 `(0, 2^31)`，以支持 `uint32` 回绕并拒绝重复、乱序和重放。
- 密钥必须至少包含 32 字节。

## 载荷格式

### CAR_TELEMETRY（17字节）

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0 | `u8` | 车辆状态：0 就绪、1 运行、2 完成、3 安全停车 |
| 1 | `u8` | 转弯：0 直行、1 小弯、2 大弯 |
| 2 | `u8` | 事件：0 无、1 启动、2 B、3 D、4 A、5 完成 |
| 3 | `u16` | 事件 ID；非零事件按此字段幂等去重 |
| 5 | `u16` | 质量标志 |
| 7 | `i32` | 从起点沿赛道正方向累计位移，毫米 |
| 11 | `i16` | 滤波后的轮速，毫米/秒 |
| 13 | `i16` | 归一化循迹误差乘 1000 |
| 15 | `u16` | 故障标志 |

车辆以 20 Hz 发送该载荷，接收端在 750 ms 后标记为陈旧。同一事件会连续发送 5 帧且保持相同 `event_id`，接收端必须按 ID 幂等处理。B/D/A 只能按照 `START -> B -> D -> A -> COMPLETE` 出现。

### TASK_SELECTION（9字节）

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0 | `u32` | 选择 ID，重发时保持不变 |
| 4 | `u32` | 当前车辆 `boot_id` |
| 8 | `u8` | 任务编号，只允许 1 或 2 |

### MISSION_STATUS（18字节）

| 偏移 | 类型 | 字段 |
| ---: | --- | --- |
| 0 | `u32` | ROS 确认的选择 ID |
| 4 | `u32` | ROS 当前确认的车辆 `boot_id` |
| 8 | `u32` | 本回执所针对的 HMI `boot_id` |
| 12 | `u8` | 阶段：预启动(0)、选择已确认(1)、已获准(2)、车辆运行(3)、完成(4)、故障(5) |
| 13 | `u8` | 已确认任务，0/1/2 |
| 14 | `u16` | 原因或故障标志 |
| 16 | `u16` | 权威状态标志：bit0 无人机链路、bit1 已解锁、bit2 视觉有效、bit3 ROS 就绪；其余位必须为 0 |

## 地址与端口所有权

示例地址只用于说明，实际地址必须由热点的 MAC-DHCP 保留表提供。

| 节点 | 示例地址 | 自有 UDP 端口 | Sender ID |
| --- | --- | ---: | --- |
| 空中 ROS | `192.168.20.1` | 42000 | `0x524F5331`（"ROS1"） |
| 车辆 | `192.168.20.2` | 42001 | `0x43415231`（"CAR1"） |
| HMI | `192.168.20.3` | 42002 | `0x484D4931`（"HMI1"） |

热点必须启用 WPA2，且 AP 客户端隔离策略必须允许"车辆 -> HMI"的显式单播。允许的端点对只有：车辆到 ROS、车辆到 HMI、HMI 到 ROS、ROS 到 HMI，以及可选的 ROS 到车辆诊断；禁止广播。
