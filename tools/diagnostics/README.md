# ED UAV 通信诊断工具

## 快速开始

```bash
# 1. 先运行自测（不需要 root，不需要 ESP32）
python3 tools/diagnostics/test_protocol.py

# 2. 启动热点（需要 root）
sudo ./tools/hotspot/setup_hotspot.sh create

# 3. 运行诊断工具（需要 root，因为绑定了 42000 端口）
sudo python3 tools/diagnostics/vehicle_comm_diagnostic.py

# 4. 给 ESP32 上电，观察诊断输出
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--key-file` | 示例密钥 | HMAC 密钥文件（十六进制文本，≥32 字节） |
| `--bind` | `0.0.0.0` | 绑定地址 |
| `--log-file` | 无 | 同时写入日志文件 |

## 链路状态判断

| 状态 | 含义 |
|------|------|
| `ONLINE` | 最近 750ms 内收到数据 |
| `STALE` | 超过 750ms 未收到数据 |

## 故障排查

### CAR 一直是 STALE
1. 检查 CAR ESP32 是否上电
2. 确认 config_local.h 中 `ROS_IP` = `192.168.20.1`
3. 确认热点未启用客户端隔离
4. 用 `ping 192.168.20.2` 测试网络层

### HMI 一直是 STALE
同上，检查 `192.168.20.3`

### 解码失败数持续增加
- HMAC 密钥不一致（检查 config_local.h 中的 AUTH_KEY）
- 协议版本不匹配

### dup/ooo 数持续增加
- 正常：同一事件重复 5 帧会导致 dup 增加
- 异常：ooo 持续增加说明数据包乱序严重
